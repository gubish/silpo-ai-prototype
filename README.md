# Сільпо — клікабельний прототип (v2, справжня верстка)

Чистий HTML/CSS/JS, без збірки та залежностей.

## Онлайн

- Прототип: https://gubish.github.io/silpo-ai-prototype/ (гілка дизайну — з перемикача; для посилання на конкретну:
  `…/silpo-ai-prototype/?branch=a`, `?branch=b` або `?branch=c`, можна з екраном: `?branch=b#listing/fruits`).
- Код: https://github.com/gubish/silpo-ai-prototype (публічний; публікується GitHub Pages з гілки `main`).
- Оновити онлайн-версію після правок (з папки `02`):
  ```bash
  git add -A && git commit -m "Що змінили" && git push
  ```
  За хвилину-дві зміни зʼявляться за посиланням.

## Як відкрити

- **Просто:** двічі клацніть `index.html` — працює офлайн, навіть з диска.
- **Через локальний сервер** (так надійніше в Safari/Firefox):
  ```bash
  cd "Silpo AI/02" && python3 -m http.server 5173
  ```
  і відкрийте http://localhost:5173

Кнопка **«На початок»** у лівому верхньому куті (поза телефоном) запускає прототип заново з головної: кошик, чат, лайки й фільтри скидаються. Під нею — перемикачі **«Дизайн A | B»** (див. «Гілки дизайну») і **«Теги v1 | v2»**. На вузьких екранах усе це сховано.

Потрібний екран можна відкрити одразу: `index.html#cart`, `#catalog`…
Лістинг і картку товару — з параметром: `#listing/fruits`, `#pdp/banana` (id товару з `js/data.js`).

## Що де правити

| Хочу змінити…                         | Файл |
|---------------------------------------|------|
| Тексти, ціни, назви товарів, підписи   | `js/data.js` |
| Картинку                              | покладіть новий файл з **тією ж назвою** в `assets/…` (або змініть шлях у `js/data.js`) |
| Кольори, шрифти, відступи, радіуси     | `css/tokens.css` (дизайн-токени з Figma) |
| Стилі конкретного екрана              | `css/screens/<екран>.css` |
| Спільні компоненти (картка товару, ціна, кнопка «+», таб-бар `UI.tabbar(активний пункт)`) | `css/components.css`, `js/ui.js` |
| Порядок/структуру блоків екрана        | `js/screens/<екран>.js` |
| Колір статус-бару для екрана           | `STATUSBAR_BG` у `js/app.js` |

## Екрани й переходи

| Екран | Адреса | Що клікабельне |
|---|---|---|
| Головна | `#home` | пошук → екран пошуку; категорії, сервіси → каталог; товари → картка; «+» додає в кошик; таб «Кошик»; лайки; каруселі тягнуться мишею |
| Каталог | `#catalog` | «‹» → головна; поле пошуку й лупа внизу → пошук; плитки → лістинг; нижня панель прокручує до розділу; чипси й перемикач «Експрес» |
| Лістинг | `#listing/fruits` | «‹» → каталог; таби-фільтри; пошук за назвою; фільтр «Лише акційні»; «+» → степер «− N шт +»; картка → PDP цього товару; плашка кошика → кошик |
| Пошук | `#search` | «‹» → туди, звідки прийшли; поле з iOS-клавіатурою, видача оновлюється з кожною літерою; підказки й історія запускають пошук; хрестик прибирає запит з історії, «Очистити» — усю; категорії; «+» → степер; рядок → картка товару; плашка кошика → кошик |
| Картка товару | `#pdp/banana` | «‹» → туди, звідки прийшли; лайк; акордеони згортаються; «Схожі товари» відкривають свої картки; «У кошик» → степер «− N шт +», над панеллю зʼявляється плашка кошика (тап → кошик) |
| Кошик | `#cart` | степер кількості (смітник при 1 шт), очистити кошик, суми й доставка рахуються наживо, «Оформити» → чекаут |
| Чекаут | `#checkout` | вибір способу, дня, часу, типу адреси; поля редагуються; оплата активна лише з галочкою 18+ → подяка |
| Подяка | `#thankyou` | обидві кнопки → головна |

## Сторінки лістингу й картки товарів

- **Сторінки лістингу** — `DATA.listing.pages`. Для прототипу є лише `fruits` — 12 фруктів:
  усе з каталогу веде туди (`defaultPage`). Нова категорія = новий ключ у `pages` + `category` у плитці каталогу.
- **«Назад» у кошику й на картці товару** веде туди, звідки прийшли (прототип памʼятає історію переходів);
  якщо прийшли з чату — повертає в чат.
- **Вміст картки товару** — `DATA.pdp.products[<id товару>]`: опис, склад, «Загальна інформація», харчова цінність, 18+, схожі товари.
  Будь-який блок можна не заповнювати — він не покажеться. Без `similar` показуються інші товари з того ж лістингу.
- Галочка 18+ на чекауті з’являється, лише якщо в кошику є товар із `warning`.

Кошик спільний для всіх екранів. Щоб при відкритті прототипу в кошику вже щось лежало —
заповніть `DATA.cart.startItems` у `js/data.js`, напр. `{ wineLail: 1, applesGreen: 2 }`.
Пороги дешевшої доставки — `DATA.cart.delivery`.

## Пошук

Figma: «Пошук та Фільтри» (`A2puFt6YsemhfZtqP2w233`, nodes 6005:20229 і 6005:20461). Порожній стан і список
категорій — за скрінами з проду. Дані — `DATA.search` у `js/data.js`, розмітка — `js/screens/search.js`.

- **Стани:** історії ще немає → «Можливо, ви шукаєте? 🔎» (чипси `suggestions`) + категорії;
  історія є → «Історія пошуку 👀» + категорії.
- **Поки набираємо** — лише відповідні запити з історії й відповідні категорії, товарів ще немає:
  «Ябл» → «Яблука» в історії та «Фрукти, овочі». Категорія підходить за своїми `keywords`
  або коли в ній є товар із такою назвою (крім добірок за правилом, як «Добрі промо»).
  Нічого не підходить — підказка `submitHint` («Натисніть «Надіслати»…»).
- **Видача (товари)** — лише після «Надіслати» на клавіатурі / Enter або тапу по підказці, запиту з історії
  чи категорії. Зверху — категорії-чипси, нижче «Товари». Змінили хоч літеру — знову підказки.
  Нічого не знайшли → текст `empty` і ті самі підказки.
- **Як шукає:** по назвах усіх товарів з `DATA.products`, порівнюючи початки слів
  («яблуко» знайде «Яблука», «банани» — «Банан»). Точні збіги стоять вище («вино» → спершу вина, потім виноград).
- **Історія:** запит потрапляє туди разом із видачею (див. вище) або коли з видачі відкрили товар.
  Щоб історія вже була при старті — `startHistory`. Скидається кнопкою «На початок».
- Поки відкрита клавіатура, плашка кошика стоїть одразу над нею, а грибочок — над плашкою
  (`placeFabs()` у `js/app.js` враховує клавіатуру на будь-якому екрані з `Keyboard.attach(input, { host: екран })`).
- Щоразу, як пошук відкривають з головної чи каталогу, поле порожнє і виїжджає клавіатура.
  «Назад» із картки товару чи кошика повертає ту саму видачу.
- **Категорії:** з `go` ведуть на лістинг (як і весь каталог — на «Фрукти»), без `go` показують свої товари прямо в пошуку
  (вода, бакалія, солодощі, вино). Іконки категорій — `assets/icons/search/` (тимчасові, намальовані вручну, — замініть файли з тими самими назвами).

## Чат ШІ-помічника

Тап по грибочку на головній відкриває повноекранний чат (верстка мобільного чату з веб-версії
`Wellness/docs/cheese`). Тексти, аватар і підказки — `DATA.aiChat` у `js/data.js`.
Машрум знає, звідки його покликали, і веде далі від цього (контекст → намір → 3–4 теги).
Функція привітання змінюється за етапом: головна — «що робимо?», каталог — «що збираємо?»,
лістинг — «який товар підійде?», картка — «чи підходить цей?», кошик — «чи все зібрали?»,
чекаут — «чи все зрозуміло?» (тут нічого не пропонуємо докупити).

- Тексти й теги — `DATA.aiChat.screens` у `js/data.js`, по блоку на екран.
- Лістинг має свій набір тегів на категорію (`byPage`), картка товару — на тип товару
  (`byKind`: фрукт, вино, решта; тип задається полем `kind` у товарі).
- Перший тег одразу показує товари, а теги під ними звужують добірку:
  «Зібрати покупки» → набір на двох на кілька днів → «На сімʼю, на тиждень» / «Тільки необхідне» /
  «Додати все в кошик». Питань без товарів на екрані намагаємося не ставити.
- Тег без `answer` показується так само, як активний, але не натискається (сценарію ще немає).
- Підстановки в текстах: `{product}`, `{category}`, `{count}`/`{countWord}`, `{total}`,
  `{discount}`, `{kcal}`/`{sugar}`/`{country}`, `{cartList}` (що зараз у кошику).
- Добірки задаються списком `items`/`ids` або правилом `rule`: `sale`, `lowSugar`, `sweetest`,
  `maxPrice`, `notInCart` (чого ще немає в кошику), `cheaper`; `similar: true` — схожі на відкритий товар.
- Якщо відкрити чат з іншої точки входу, Машрум вітається заново в новому контексті,
  а вже почату розмову лишає вище.

Теги під привітанням — готові сценарії: помічник відповідає й показує картки товарів
(екран під чатом не змінюється — закриваєте чат і ви знову на головній). Сезонний тег
міняє назву й добірку за порою року (`label` / `items` з `winter`/`spring`/`summer`/`autumn`);
щоб показати конкретну пору, задайте `DATA.aiChat.season`.
Кожна відповідь закінчується тегами наступних кроків (`next` у `DATA.aiChat.openers`).
Тег без відповіді показується блідим і не натискається — це місце для майбутнього сценарію.
«Додати все в кошик» справді кладе в кошик товари з карток над відповіддю.
На будь-яке інше повідомлення помічник відповідає текстом `fallback` і знову пропонує стартові теги.

Прокрутка як у чат-ботах: готова відповідь помічника стає першою на екрані (ваше питання
відʼїжджає вгору). Якщо під екраном лишилась частина розмови — прокрутили вгору або
виїхала клавіатура, — над полем вводу зʼявляється стрілка ↓ до кінця розмови.

Поле вводу: зліва фотоапарат (відкриватиме поп-ап — поки без дії). Щойно зʼявляється текст,
поле розгортається: текст зверху, фотоапарат і кругла «Надіслати» (стрілка вгору) внизу по кутах.
Поле росте разом із текстом до 5 рядків (`--ai-input-max-h` у `css/tokens.css`), далі текст
прокручується всередині. Enter — надіслати, Shift+Enter — новий рядок.

Тап у поле вводу чату — знизу виїжджає iOS-клавіатура (українська розкладка, «123», Shift,
«стерти», «Надіслати»). Клавіші друкують у поле; з клавіатури компʼютера теж можна друкувати.
Розкладка й підписи — `DATA.keyboard`, кольори й висота — `--kb-*` у `css/tokens.css`.
Іншим полям клавіатуру можна підключити одним рядком: `Keyboard.attach(input)`.

## Гілки дизайну A / B

Два напрями всього прототипу, перемикаються кнопками «Дизайн A | B» поза телефоном.

- **A** — основний прототип, усі файли як є.
- **B** — надбудова над A: змінюється лише те, що описано у файлах гілки, решта (кошик, навігація,
  чат, пошук) — спільна.

**Що зараз відрізняє B:**
- Машрума немає як плаваючої кнопки на жодному екрані — він у таб-барі замість «Покупок»
  (екран перемалювали — грибочок у новому таб-барі зʼявляється сам: `Mascot.attach` у `js/ai-assistant.js`),
  без підпису й більший (займає місце іконки й підпису). Тап відкриває чат, настрої ті самі.
- Головна: біля пошуку немає кнопки сканування штрихкоду — вона разом із QR-кодом у **віджеті сканерів**
  на місці QR (`js/branches/b-scan.js`, `css/branches/b-scan.css`, тексти — `scanDial` у `js/branches/b.js`).
  Тап по помаранчевій кнопці — вона стає «×», екран затемнюється, а дугою вгору й уліво по черзі вилітають
  три кнопки з підписами: Власний рахунок (QR-код) · Перевірка цін · Вільнокаса (радіальне меню). Тап по пунктах поки нічого не робить
  (екранів сканерів у прототипі немає); закрити — «×» (білий), тап по затемненню, Esc, інший екран.
  Відстань кнопок від центру й кути дуги — `radius` / `angles` у `js/branches/b-scan.js`.
- Каталог: замість нижньої стікі-панелі (пошук, чипси категорій, «доставка за 1 ₴») —
  таб-бар головної з активним пунктом «Доставка» і Машрумом.
- Лістинг: без нижньої стікі-панелі (меню, пошук, кнопка кошика). Фільтр — у правому верхньому куті
  поруч із сортуванням, «Лише акційні» відкривається під табами. Внизу — таб-бар з активною «Доставкою» і Машрумом;
  суму кошика видно на пункті «Кошик».
- **Картка товару як у Amazon** (швидкий перегляд): тап по товару на головній, у лістингу, пошуку чи в чаті МГ відкриває картку поверх екрана — назва, рейтинг, фото, ціна, опис, 3 рядки
  «Загальної інформації», 18+. Сусідні товари того ж списку визирають з боків і гортаються свайпом
  (мишею — перетягуванням, тачпадом — двома пальцями вбік, стрілками ← →; один жест — одна картка). «Усі деталі» — повна картка, «У кошик» → степер.
  Закривається хрестиком, тапом повз картку або Esc; поки вона відкрита, таб-бар ховається.
  У чаті Машрума — так само: тап по товару з каруселі відповіді відкриває картку поверх чату, сусіди — інші
  товари тієї ж каруселі; «Усі деталі» — повна картка, «Назад» — знову в розмову.
  Товари в «Схожих товарах» відкривають повну картку.
  Код — `js/branches/b-quickview.js`, стилі — `css/branches/b-quickview.css`, тексти — `quickView` у `js/branches/b.js`.
- Повна картка товару: без плаваючої плашки кошика над панеллю ціни й «У кошик»; таб-бару немає.
- Таб-бар має легку тінь угору.
- **«Помічник може допомогти»: жовтий брендований чип = дія через Машрума** (`js/branches/b-mg.js`, `css/branches/b-mg.css`).
  Сталий патерн для всього продукту: блок «Помічник може допомогти» з аватаром (один раз) + жовті чипи того ж вигляду,
  що й теги в чаті. Тап не застосовує фільтр і не відкриває сторінку — відкриває чат МГ, де вибраний намір
  стає першою реплікою, а МГ уточнює («Зараз підберу. Просто солодкі чи…?») або одразу підбирає товари.
  Чипи — мовою наміру гостя («Хочу солодкі яблука»), не назвами AI-функцій. Звичайні фільтри, навігація й кнопки
  цей стиль не використовують.
  - Пошук — під класичними підказками, чипи залежать від запиту: «яблука» → Хочу солодкі яблука / Яблука для шарлотки /
    Зібрати фрукти на тиждень; «вино» → До вечері / До сиру / Допоможи вибрати; «пральний порошок» → Для дитячих речей /
    Для кольорового / Допоможи вибрати; решта запитів із товарами → Допоможи вибрати (`search.ai` у `js/branches/b.js`).
  - Головна — перед «Популярними категоріями»: Зібрати покупки / Хочу щось поїсти / Знайти вигідне / Подбати про себе;
    каталог — під пошуком і «Акційними пропозиціями»: Зібрати на кілька днів / Щось на вечерю / Мої звичні продукти.
  - Лістинг «Фрукти» — під табами: Допоможи вибрати / Найсолодші / До вина; картка товару — під назвою:
    З чим поєднати? / Знайти схоже; кошик — над товарами (якщо не порожній): Чогось не вистачає? / Що з цього приготувати?
    чекаут — у кінці, над панеллю оплати: Коли привезуть? / Змінити доставку / Що з пакуванням?
    (`mg` у `js/branches/b.js`; `opener` — готовий сценарій чату цього екрана).
  - Чат, відкритий чипом із пошуку, закривається на екран, з якого викликали пошук (не в сам пошук).
  - Новий екран: `MG.block(чипи, { row: true })` у його розмітці гілки B.
- **Пошук: підказки під час набору, як в Amazon** (`js/branches/b-search.js`, `css/branches/b-search.css`,
  дані — `search` у `js/branches/b.js`). Поки гість набирає (до «Надіслати»), під полем один компактний список,
  що вміщується над клавіатурою: запити з історії (хрестик — прибрати) → товари (тап — картка як у Amazon,
  «+» — у кошик) → категорія («яблука у «Фрукти, овочі»»). Набране — звичайним шрифтом, доповнення — жирним.
  Нижче, окремо, — блок «Помічник може допомогти».
  - В історії на старті вже є «яблука зелені» й «вода мінеральна» (`search.startHistory`) — щоб було що підтягувати.
  - **Демо:** щоб не набирати, перша ж літера після відкриття пошуку підставляє «яблука» (`search.demoQuery`;
    `null` — вимкнути). Стерли хрестиком — далі набирається своє (напр. питання).
  - **«Шукайте або запитайте»** — плейсхолдер пошуку на головній, у каталозі й на екрані пошуку: натяк, що тут
    можна почати розмову з помічником. Запит-питання (закінчується «?» або починається з `search.askWords`:
    що, як, порадь, хочу…) — першим чипом у блоці помічника, а «Надіслати» відкриває чат МГ замість видачі.
    Відповідь — за ключовими словами (`aiChat.shop.questionRoutes`: «вечеря» → «Хочу щось поїсти»,
    «знижки» → «Знайти вигідне»…), інакше — стандартна відповідь чату.
- **Чат Машрума — частина застосунку** (`js/branches/b-chat.js`, тексти — `aiChat.shop` у `js/branches/b.js`):
  - зʼявляється одразу, без виїзду знизу (закриття — як було);
  - без плашки кошика; під полем вводу — таб-бар, кошик на ньому живий (кількість і сума);
  - клавіатура відкрита → таб-бар схований (розмова → поле → клавіатура); після «Надіслати» клавіатура ховається, таб-бар повертається;
  - «Додай банан» / «Купи 2 манго» — МГ кладе товар і лише підтверджує: «Додав банан — 170.00 ₴.» Кошик не пропонує;
  - кошик пропонується лише після завершення місії: «Додати все в кошик» після добірки →
    «З фруктовим салатом наче все. У кошику 7 товарів на … ₴» + [Перевірити кошик] [Продовжити покупки];
  - місію можна почати тегом («Зібрати покупки») або текстом: «Збери фруктовий салат», «Збери покупки» (`missions`);
  - кошик із чату (пункт таб-бару чи «Перевірити кошик») — звичайний екран кошика, «Назад» — знову в розмову;
  - змінили кошик вручну й повернулись у чат — МГ каже, що кошик оновився, і називає актуальні кількість і суму.
  - Тап по «Головна» / «Доставка» в таб-барі чату закриває чат; тап по Машруму нічого не робить.
- Код — `screens.home` / `screens.catalog` / `screens.listing` / `screens.pdp` у `js/branches/b.js` (доповнюють основні екрани),
  розміри й відступи таб-бару — `css/branches/b.css`.

| Що змінити в гілці B | Де |
|---|---|
| Кольори, шрифти, відступи, вигляд компонентів | `css/branches/b.css` — кожен селектор починається з `[data-branch="b"]`; токени перевизначаються так само: `[data-branch="b"] { --blue-500: … }` |
| Тексти, ціни, картинки, склад блоків | `data` у `js/branches/b.js` — лише те, що відрізняється від `js/data.js`, з тією самою вкладеністю. Об'єкти зливаються, масиви й значення замінюються цілком |
| Розмітку цілого екрана | `screens` у `js/branches/b.js` — скопіюйте функцію з `js/screens/<екран>.js` і правте копію, або викличте основну (`BaseScreens.<екран>`) і доповніть результат, як зроблено з головною |

- Правки в основних файлах (`js/data.js`, `css/…`, `js/screens/…`) діють на **обидві** гілки, якщо B їх не перевизначає.
  Тому спільне правимо в основі, а відмінності — лише у файлах гілки.
- Перемикання перезапускає прототип **на тому ж екрані** (кошик і чат — з нуля). Вибір памʼятається
  в браузері й переживає «На початок».
- Посилання на конкретну гілку: `index.html?branch=b#pdp/banana`.
- Назви кнопок і підказки — `Branch.list` у `js/branches.js`. Нова гілка = рядок у `list` +
  файл `js/branches/<id>.js` (і за потреби `css/branches/<id>.css`) з підключенням в `index.html`.

### Гілка C — демо: A + пошук і теги МГ із B

- База — **A**: Машрум у правому нижньому куті з острівцем, нижня панель лістингу, звичайні PDP і чат.
  Каталог — без нижньої стікі-панелі (пошук, чипси категорій, «доставка за 1 ₴»).
- **Пошук — із B**: підказки під час набору, «Шукайте або запитайте», демо-запит «яблука»,
  питання («Що приготувати на вечерю?») відкриває чат МГ.
- **Жовті теги «Помічник може допомогти» — лише** на каталозі, лістингу (PLP), картці товару (PDP) і в кошику
  (на головній і в чекауті їх немає). В один рядок: маленький МГ зліва стоїть на місці (тап — чат),
  теги скролляться поруч, без заголовка (`MG.block(…, { compact: true })`, стилі — кінець `css/branches/b-mg.css`).
  У пошуку блок лишається із заголовком — там він відділяє підказки від допомоги МГ.
- Код — `js/branches/c.js`; тексти пошуку й тегів беруться з `js/branches/b.js` (правка там діє на B і C).
  Спільні надбудови вмикає `features` у `Branch.list` (`'search'` — `b-search.js`, `'mg'` — `b-mg.js`).
- **Хедер лістингу — як у застосунку** (`screens.listing` у `js/branches/c.js`, стилі — `css/branches/c.css`):
  сірий хедер (назва + чипси) стікі разом зі статус-баром; прокрутили — мутне скло, як нижня панель.
  Чипси заокруглені, активна — синя рамка з галочкою (`assets/icons/check-blue.svg`). Товари й теги МГ — на білому
  «аркуші» з заокругленими верхніми кутами.
  Пошук у нижній панелі — той самий, що на головній: «Шукайте або запитайте», тап — екран пошуку (з підказками B);
  кнопки меню каталогу біля нього немає — пошук на всю ширину.
- На екрані пошуку МГ у правому нижньому куті немає — натомість **МГ праворуч від поля пошуку**, кнопка в чат
  (`js/branches/c-search.js`, тексти — `mgSearch` у `js/branches/c.js`). Поле порожнє — привітання головної;
  у полі запит («яблука») — у чаті ваша репліка, знайдені товари й жовті теги-наміри з підказок пошуку;
  запит-питання — МГ відповідає як на повідомлення. Закрили чат — знову пошук із тим самим запитом.
- Поза телефоном замість перемикача вигляду острівця — **«МГ у тегах»**: вмикає й вимикає аватарку МГ на початку
  рядка жовтих тегів (`mgAvatarToggle` у `js/branches/c.js`; вибір памʼятається в браузері).
- **Машрума можна перетягнути** (`js/branches/c-drag.js`, `css/branches/c-drag.css`, тексти — `mgDrag` у `js/branches/c.js`):
  тап — чат; потягнули — МГ їде за пальцем і лишається там, де відпустили. На стікі-футер (нижня панель,
  плашка кошика, клавіатура) кинути не можна — відʼїде трохи вище; на інших екранах теж тримається над їхнім футером.
  Викинули за межі екрана або різко жбурнули до краю — зникає; внизу снекбар «Машрум сховався · Повернути»
  з таймером (як у Figma, node 6087:10273), «На початок» теж повертає МГ у кут. Поки МГ не в кутку, острівець мовчить.
- Посилання: `index.html?branch=c`.
- Технічно: у `<html>` атрибут `data-branch="a"|"b"`; `Branch.apply()` на старті (з `App.init`)
  зливає `data` гілки з `DATA` і підміняє екрани з `screens`.

### Дизайн тегів чату — дві версії (експеримент)

| Версія | Вигляд | Файл |
|---|---|---|
| **v1** (увімкнена) | капсули з мʼяким кольоровим світінням, стовпчиком, 32px | `css/ai-chips-v1.css` |
| **v2** | те саме, але заливка розмита (`blur`) і розчиняється у фоні — без чіткої капсули | `css/ai-chips-v2.css` |

- Перемикач «Теги v1 | v2» — під кнопкою «На початок» (поза телефоном). Вибір памʼятається
  в браузері й переживає «На початок». Версія за замовчуванням — `DATA.aiChat.chipsVersion` у `js/data.js`.
- v2 — це надбудова над v1: у ній змінено лише декоративний шар `::before`
  (розміри, шрифт, кольори, анімація й поведінка — з v1). Тому v1 не можна видаляти, поки є v2.
- Технічно: чат отримує атрибут `data-chips="v1"` або `data-chips="v1 v2"`, стилі версій
  підключаються через селектори `[data-chips~="v1"]` / `[data-chips~="v2"]`.
- Жовті чипи МГ поза чатом (гілка B, `.mg-chip`) перемикаються разом із тегами: атрибут `data-chips`
  стоїть і на `<html>`, тож у файлі версії додайте селектор `[data-chips~="vN"] .mg-chip` поруч із `.ai-chip`.
- Нова версія = новий файл `css/ai-chips-v3.css` + підключення в `index.html` + рядок
  у `chipVersions` у `js/ai-chat.js` (`{ v1: 'v1', v2: 'v1 v2' }`) — кнопка в перемикачі зʼявиться сама.
- Кольори тегів — `--ai-chip-*` у `css/tokens.css`.

## Острівець: Машрум звертається до гостя (гілка A)

`js/mg-island.js`, `css/mg-island.css`, тексти — `DATA.aiChat.island` у `js/data.js`.
Ідея — з motion-демо `../mg-island-demo` (там лише приклад; розміри й відступи тут — наші).

- **Спокій:** плаваючий грибочок, над ним QR.
- **Звернення:** біла «пігулка» заввишки з грибочок у спокої (64px) розгортається вліво з-під нього,
  Машрум відкочується (один оберт) у її лівий край і трохи зменшується (`--isl-scale: 0.8`), поруч — текст
  без підпису (14px). На місці грибочка — біле кругле коло з хрестиком. Текст і хрестик проявляються із затримкою.
- **Звернення на головній:** «Вперше тут? Зберу кошик і поясню доставку» — для нових гостей, які збирають кошик,
  щоб зрозуміти правила гри (сума, ціна доставки). Текст до ~45 символів — два рядки при 14px.
- **Тап по тексту** — чат: звернення як перша репліка МГ, далі його продовження з товарами й тегами (`reply`).
  На головній МГ збирає базовий кошик і пояснює доставку за тими самими правилами, що й кошик
  (`DATA.cart.delivery`): підстановки `{sum}`, `{deliveryRules}`, `{deliveryHere}` у `reply.answer`.
  Тап по Машруму — як завжди чат; хрестик, Esc або перехід на інший екран — згорнути.
- **Тригер (для тесту):** на головній проскролили «Тільки онлайн» і на екрані зʼявився банер за ним.
  Для демо — щоразу, як банер знову заїжджає на екран (прокрутили вище й назад); `island.repeat: false` —
  раз за сесію. Поверх відкритого чату не зʼявляється.
- **Експеримент: тема** — перемикач «Острівець: Світлий · Темний | Скло» під перемикачем тегів (вибір памʼятається;
  за замовчуванням — `island.theme` / `island.glass`). Світла — `css/mg-island.css`, темна й скло — `css/mg-island-themes.css`.
  «Скло» вмикається поверх будь-якої теми: напівпрозора матова поверхня (розмиває й підсилює кольори під собою),
  тонка світла окантовка, відблиск згори зліва. Технічно — атрибути `data-island-theme` і `data-island-glass` на `<html>`.
- Розміри — змінні `--isl-*` на початку `css/mg-island.css`; ширину «пігулки» й шлях грибочка рахує JS
  від ширини телефона. Показати звернення з коду: `MgIsland.speak('home')` (ключ із `DATA.aiChat.island`).

## Rive-асистент

Грибочок висить у правому нижньому куті **на всіх екранах** (QR-кнопка — лише на головній, над грибочком).
Висоту рахує `placeFabs()` у `js/app.js`: нижня панель екрана + плашка кошика, якщо вона видима,
«відштовхують» його вище. Новий екран із власною нижньою панеллю треба додати в перелік селекторів там.

**Настрої Машрума** — вираз обличчя + колір сяйва: жовтий задоволений, задумливий, сонний (заплющені очі;
сяйво поки жовте — синьо-фіолетове з файлу на 32px брудне, поле `glow` у `moods`),
червоний буркотливий (`DATA.aiChat.moods`). Відкрили чат — «О. Прокинувся»: спершу сонний, за мить жовтий;
«друкує…» — задумливий; відповіді — жовті, окремим можна задати `mood: 'grumpy'` тощо.
Аватар Машрума з підписом — лише над останньою відповіддю (живий, у поточному настрої); старі відповіді —
просто бульбашки, як історія листування. Той самий настрій — і в грибочку на головній.
Зміна настрою плавна: новий проявляється поверх старого (`js/ai-assistant.js`, клас `Mushroom`).
Колір і вираз беруться з анімацій `face-<настрій>` і `face-<настрій>-gradient` у `.riv`;
стейт-машину не використовуємо — вона не вмикає кольори. Прямі зрізи сяйва по краях — від меж
artboard у самому `.riv` (виправляється в Rive: ширший artboard).


Після заміни `assets/rive/mushroom_mvp.riv` запустіть `sh tools/embed-rive.sh` —
це оновить вшиту копію, потрібну для відкриття з диска (`file://`).
Через сервер файл `.riv` підхоплюється напряму.
